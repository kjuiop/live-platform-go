PR 리뷰 코멘트를 코드에 반영합니다.

추가 컨텍스트: {{args}}

다음 순서로 진행하세요:

## 1. 대상 파악

- `{{args}}`가 있으면 해당 내용을 반영할 파일과 위치를 파악합니다
- 관련 파일을 읽어 현재 코드 상태를 확인합니다

## 2. 리뷰 타당성 검토

코드를 수정하기 전에 **반드시 먼저** 리뷰 내용이 타당한지 검토합니다:
- 지적된 문제가 실제로 존재하는지 코드에서 확인합니다
- 제안된 해결책이 올바른지 분석합니다
- 타당하지 않은 경우(잘못된 지적, 불필요한 변경, 부작용이 더 큰 경우) **진행을 중단**하고 이유를 설명합니다
- 타당한 경우 "이 리뷰는 타당합니다" 를 명시하고 다음 단계로 진행합니다

## 3. 변경 계획 설명

타당성 검토 통과 후, 코드를 수정하기 전에 다음을 텍스트로 설명합니다:
- 어떤 파일의 몇 번째 줄을 수정하는지
- 무엇을 어떻게 바꾸는지 (before/after 코드 포함)
- 변경으로 인해 다른 파일에 영향이 있는지

## 4. 코드 반영

설명 후 실제 파일을 수정합니다:
- Edit 툴로 파일을 직접 수정합니다
- 여러 파일에 걸친 변경이면 순서대로 모두 반영합니다
- 수정 후 변경된 파일을 다시 읽어 결과를 확인합니다

## 5. 결과 요약

- 수정된 파일 목록
- 변경 요약 한 줄씩

주의사항:
- 이 커멘드는 사용자가 명시적으로 코드 수정을 요청한 것이므로 Go 코드를 직접 수정합니다
- 요청한 범위 외의 코드는 건드리지 않습니다
- 빌드/테스트에 영향을 줄 수 있는 변경이면 `make test` 실행을 안내합니다
